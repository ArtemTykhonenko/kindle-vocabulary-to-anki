## 🌟 Як це працює

**Kindle Vocabulary to Anki** поєднує читання на вашому Amazon Kindle із вивченням слів у Anki — додаток працює **на 100% локально у вашому браузері** без жодного бекенд-сервера та без ШІ-ключів.

1. **1. Add Words (Додавання слів)**: Підключіть Kindle через USB і перетягніть файл `system/vocabulary/vocab.db` у вікно браузера (або вставте власний список слів текстом). База даних SQLite обробляється локально через WebAssembly (`sql.js`).
2. **2. Translate & Edit (Переклад та редагування)**: Автоматичний переклад слів (за замовчуванням **Англійська → Українська**, доступно понад 14 мов перекладу) та збагачення кожної картки **фонетичною транскрипцією IPA**, **словниковим визначенням**, **оригінальною цитатою з книги Kindle**, **прикладом вживання** та **живою MP3-озвучкою**.
3. **3. Export (Експорт у Anki та очищення Kindle)**: Завантажте готову колоду для Anki (`.txt`) з автоматичною підтримкою світлої й темної теми та вбудованою кнопкою озвучки, синхронізуйте картки напряму з Anki Desktop через **AnkiConnect**, а також завантажте чистий файл `vocab.db` для очищення словника на самому Kindle.

## ✨ Ключові можливості

### 🃏 Готові до навчання картки Anki
Кожна картка автоматично містить:
- **Переклад** обраною мовою (за замовчуванням — українська `uk`).
- **Транскрипцію IPA та тлумачення** зі словника з автоматичним визначенням початкової форми слова (леми).
- **Підсвічування слова в контексті**: зберігається оригінальне речення з книги Kindle, де ви натиснули на слово, а також додається приклад використання.
- **Аудіовимову (`🔊`)**: працює як у веб-інтерфейсі, так і всередині експортованих карток у самому Anki (жива вимова носія мови з Oxford Dictionary CDN із резервним MP3-словником).
- **Автоматична Світла та Темна тема**: експортовані картки автоматично підлаштовуються під тему Anki Desktop, AnkiMobile та AnkiDroid.

### 🧹 Очищення словника Kindle (`vocab.db`)
В Amazon Kindle немає простої кнопки «Очистити весь словник» на самому пристрої. Після експорту карток натисніть **Download Clean vocab.db** на екрані експорту та замініть файл `system/vocabulary/vocab.db` на Kindle через USB, щоб повністю очистити старі слова.

### ⚡ Пряма синхронізація з Anki Desktop (AnkiConnect)
Окрім завантаження готового `.txt` файлу, ви можете відправляти картки в Anki Desktop в один клік за допомогою доповнення [AnkiConnect](https://ankiweb.net/shared/info/2055492159) (код `2055492159`). На сторінці експорту вбудовано покрокову інструкцію та кнопку копіювання готового JSON-конфігу для доменів `kindle2anki.online` та `kindletoanki.online`.

### 🔒 100% Автономність та Приватність
- **Без сервера**: чистий клієнтський додаток (Vite + React + TypeScript SPA).
- **Без ШІ**: використовуються класичні словникові та перекладацькі API напряму з браузера.
- **Локальне збереження**: поточна колода та бінарний шаблон `vocab.db` зберігаються виключно у `IndexedDB` вашого браузера.

## 🚀 Запуск локально

**Вимоги**: [Node.js](https://nodejs.org/) (v18+)

1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Запустіть локальний сервер розробки:
   ```bash
   npm run dev
   ```
3. Відкрийте `http://localhost:3000` у браузері.

---

## ☁️ Статичний деплой (Serverless)

Оскільки додаток працює повністю на стороні клієнта, його можна розмістити на будь-якому статичному хостингу (Vercel, Cloudflare Pages, Netlify, GitHub Pages):

1. Зберіть продакшн-білд:
   ```bash
   npm run build
   ```
2. Завантажте вміст папки `dist/` на ваш хостинг.
